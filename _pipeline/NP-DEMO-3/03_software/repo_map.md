## 2. threshold_eth.py — Why It MUST NOT Be Used for NP-DEMO-3

- **File**: `Optimized Python/analyses/threshold_eth.py`
- **Algorithm**: floor-clips ETH at 0.11 (i.e., any sample >= 0.11 is ethanol)
- **Difference from contract**: NP-DEMO-3 requires mean-subtraction of the ENTIRE ETH trace before thresholding at 0.05. threshold_eth.py does neither: no mean subtraction, different threshold (0.11 vs 0.05), different logic.
- **Contract prohibition**: "reusing threshold_eth.py (floor-clip at 0.11) in place of detect_eth_contact" is explicitly listed as a prohibited change.
- **Action**: Do NOT import or call threshold_eth. Write detect_eth_contact as a new independent function.

## 3. detect_eth_contact — New Kernel Function

**Status**: NEW — no MATLAB reference exists. Fixture will be established from first validated run (contract OPEN-001 resolution).

**Recommended file**: `C:\Projects\Repos\Neuropixels\_pipeline\NP-DEMO-3\03_software\detect_eth_contact.py`
(Alternatively: `Optimized Python/analyses/detect_eth_contact.py` beside other analyses — do NOT edit any existing kernel file to accommodate it.)

**Proposed signature**: `def detect_eth_contact(D: dict, eth_threshold: float = 0.05) -> dict`

**Algorithm** (from contract, verbatim):
1. Subtract the mean of the ENTIRE ETH time series for the experiment: `ETH_ms = D['ETH'] - np.mean(D['ETH'])`
2. Threshold: samples strictly above 0.05 = ethanol contact; samples at or below 0.05 = control
3. Count contiguous above-threshold runs as n_trials
4. Fixed rule: identical 0.05 threshold for ALL 6 sessions — NO per-experiment adjustment

**Expected outputs added to D** (or returned as separate dict):
- `D['ETH_ms']` — mean-subtracted ETH trace (same length as D['ETH'])
- `D['eth_contact_mask']` — boolean array (True = ethanol, False = control)
- `D['n_trials']` — integer count of discrete contiguous above-threshold runs
- `D['eth_threshold']` — applied threshold value (0.05)

**Acceptance criteria**: Binary mask and integer n_trials must match exactly (deterministic rule, no tolerance — RESULT-eth-mask).

**Fixture approach**: No MATLAB reference. After code review + manual inspection confirm correctness, the initial outputs become the golden slice for regression testing.

## 7. NP-DEMO-1 Pattern Reference
