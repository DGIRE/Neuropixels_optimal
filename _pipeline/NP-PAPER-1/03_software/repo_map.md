### 1.2 `compute_sniff_phase`
- **File**: `Optimized Python/analyses/compute_sniff_phase.py`
- **Import**: `from analyses.compute_sniff_phase import compute_sniff_phase`
- **Signature**: `compute_sniff_phase(D: dict, threshold_std: float = -0.5) -> dict`
- **PINNED PARAMETER**: `threshold_std = -0.5` (PROH-004/PROH-007) — never adjusted without separate human sign-off.
- **Algorithm** (verified by reading the file): low-pass FIR (order-20, ~40 Hz, Hamming) `filtfilt` of SNF -> z-score (ddof=1) -> downward threshold crossings at `SNF_z < threshold_std` with a `MIN_ISI = round(0.05*LV_Fs)` debounce -> per-onset phase ramp 0..1 capped at 0.5 s (`-1` outside every cycle).
- **Key outputs added to D**:
  - `D['SNF_PH']` — (n,) float64, instantaneous phase 0..1 within a sniff cycle; **`-1` sentinel = outside any valid cycle** (the noise/non-sniff marker NP-PAPER-1's `build_valid_sniff_mask` must honor, per PROH-004/RQ-021).
  - `D['sniff_onsets_s']` — (n_sniffs,) float64, onset times in seconds = `onsets_0based / LV_Fs`.
  - `D['sniff_onsets']` — 1-based sample indices (MATLAB convention) — do not use directly for time math, use `sniff_onsets_s`.
  - `D['sniff_dur_s']` — **a SCALAR** (`float(np.median(dur_s))`), the median sniff-cycle duration across the WHOLE recording. **HAZARD**: this is NOT a per-sniff array. The contract's `build_valid_sniff_mask` needs the per-sniff ISI DISTRIBUTION (to compute its 5th/95th percentile per RQ-020) — that must be derived fresh as `np.diff(sniff_onsets_s)`, it is not exposed anywhere in D. Do not mistake `sniff_dur_s` for a per-sniff series.
  - `D['sniff_thr']` — the threshold value used (== `threshold_std`).
- **Golden Fixture tolerances** (stage `08_sniff_phase`): `SNF_filt` rtol=1e-06/atol=1e-09; `SNF_z`, `sniff_onsets_s`, `sniff_thr` rtol=atol=1e-12; `SNF_PH` rtol=atol=1e-12; `sniff_onsets` exact (rtol=atol=0).

**1. `extract_full_lfp(files, channel_indices, checkpoint_dir=None)`**
Additive, does NOT edit `load_experiment_data.py`. Re-derives the full-duration LFP for only the 5 selected channels, preserving the exact same `butter(4, 400/(NP_Fs/2), 'low')` -> decimate-to-1000 Hz path. **Regression anchor (OUT-026, blocking)**: restricted to the first 10 s, must equal the CURRENT `load_experiment_data` 10-s output channel-for-channel. Because this compares the new Python path against the same Python code path (not MATLAB), a tight tolerance (contract specifies rtol<=1e-9/atol<=1e-12) is achievable and appropriately tighter than the LFP-vs-MATLAB fixture tolerance (1e-6/1e-9) — these are different comparisons, not a conflict.

**2. `select_five_depths(xcoords, ycoords, valid_lfp_channels)`**
Deterministic, level-1 (exact). Min/max ycoord among channels with both a valid LFP row and a ycoord; 5 target fractions [0, 0.25, 0.5, 0.75, 1.0] of the range; nearest channel by |ycoord-target|, ties broken by lower channel index (which — because Neuropixels channels sharing a ycoord differ only in column/xcoord and tie exactly in ycoord-distance — deterministically fixes one column throughout, satisfying RQ-016 without an extra free choice). Depth 1..5 labeled tip->surface.

**3. `build_window_control_mask(D, window_starts, window_len_s)`**
Thin wrapper: get `eth_contact_mask` from `detect_eth_contact` (LV_Fs clock), map to the LFP clock (shared recording clock, resample by index/time not by re-detecting), mark a window control-eligible only if it contains ZERO ethanol samples. No new threshold introduced.

**4. `build_valid_sniff_mask(D_with_phase)`**
From `compute_sniff_phase` output: ISI = `np.diff(sniff_onsets_s)` (must derive this locally — see §1.2 hazard, it is not in D); mark spans with ISI outside [5th, 95th] percentile of THIS experiment's ISI distribution as invalid; additionally mark any span where `SNF_PH == -1` invalid. Output a per-LFP-sample boolean mask + the retained instantaneous sniff-rate series (1/ISI per inter-onset interval) for the Fig 1C/1D overlays.

**5. `resample_snf_to_lfp(SNF, LV_Fs, LFP_Fs, n_lfp_samples)`**
Raw SNF (never `SNF_PH`, per PROH-009) upsampled from ~125 Hz to ~1000 Hz via polyphase/band-limited interpolation on the shared clock. Theta (2-12 Hz) is far below the SNF Nyquist (~62 Hz) so no aliasing risk.

**6. `multitaper_psd_coherence(lfp_ch, snf_lfp_rate, control_valid_windows, fs=1000.0)`**
Pinned per RQ-040: 4-s windows, 50% overlap, 7 Slepian tapers (NW=4, K=2*NW-1=7), frequencies from 0.25 Hz. `C(f) = |S12(f)| / sqrt(S1(f)*S2(f))` (RQ-023, transcribe verbatim — do not substitute a different coherence normalization such as `|S12|^2/(S1*S2)`, which is a different, also-common definition). Validate against a synthetic fixture (two signals with known coherence) at rtol 1e-6/atol 1e-9 per DATA-002; the paper's reference implementation (github.com/Sid-Rafilson-1617/sniff-LFP) may seed the oracle design.

**7. `circular_shift_null(lfp_ch, snf_lfp_rate, control_valid_windows, n_shifts=1000, seed=5489)`**
>=1000 circular shifts of SNF relative to LFP, recompute windowed coherence each time, 95th percentile per frequency = threshold. Seed 5489 pinned (lab convention) — must be bit-for-bit reproducible; this is itself a blocking failure condition (RQ-038) independent of the coherence engine's own fixture tolerance.

**8. `reduce_theta_coherence(coh_f, freqs, null_threshold_f)`**
Deterministic reduction: mean theta coherence (primary, 2-12 Hz mean), peak theta coherence + its frequency, significant-theta fraction (fraction of 2-12 Hz band exceeding null), peak-coherence percentile within the null.

**9. `depth_statistics(theta_coh_table)`**
Mixed-effects LRT (statsmodels `MixedLM`, depth fixed/experiment random intercept, vs intercept-only) + Friedman (`scipy.stats.friedmanchisquare`) + Holm-corrected exact two-sided Wilcoxon post-hoc (`scipy.stats.wilcoxon(..., mode='exact')`) only if the omnibus is significant (p<0.05).
